# Project 04 - Bash Scripting for Recon Automation

> **Status:** Planned
> Part of [00 - Foundations](../README.md).

## Objective
Build small Bash scripts that automate repetitive recon steps — host discovery, port sweeps, service banner collection, and output parsing — so the early phase of an engagement is fast and repeatable. Each script writes clean, greppable output and chains into the next step, with a short Detection note on how the generated traffic would look in logs.

> All scripting is run against hosts I own or isolated lab targets I control. No unauthorized targets.
