# Project 06 - Python for Offensive Tooling

> **Status:** Planned
> Part of [00 - Foundations](../README.md).

## Objective
Move from Bash one-liners to proper Python tooling — using `sockets`, `requests`, and `argparse` to build small, reusable command-line tools (port/banner scanner, HTTP enumerator, simple fuzzer). Focus on clean CLI design, error handling, and output that feeds the rest of the workflow, with a short Detection note on how each tool's traffic appears in logs.

> All tooling is tested only against hosts I own or isolated lab targets I control. No unauthorized targets.
