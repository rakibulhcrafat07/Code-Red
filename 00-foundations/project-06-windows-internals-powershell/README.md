# Project 06 - Windows Internals & PowerShell Fundamentals

> **Status:** Planned
> Part of [00 - Foundations](../README.md).

## Objective
Build a working understanding of Windows internals (processes, tokens, services, registry, the security model) and PowerShell as the day-to-day tool for enumeration and automation on Windows hosts. Groundwork for later AD, privilege-escalation, and evasion sections, with a short Detection note on how common PowerShell activity surfaces in logs (Script Block Logging, Sysmon).

> All work is done on lab VMs I own or control. No unauthorized targets.
