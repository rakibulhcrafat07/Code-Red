# Phase 1 — Beginner-Friendly Foundations

**Suggested pace:** Month 1–2
**Goal:** Before attacking anything, understand how systems and networks normally behave.

## Core Topics

- Networking: OSI/TCP-IP model, ports & protocols, subnetting, DNS, HTTP/HTTPS
- Linux fundamentals: filesystem, permissions, bash, SSH
- Windows fundamentals: Active Directory basics, users/groups, PowerShell basics
- Scripting: Python basics (requests, sockets) and Bash
- Security fundamentals: CIA triad, common vulnerability classes, intro to MITRE ATT&CK
